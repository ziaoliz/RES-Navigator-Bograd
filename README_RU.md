# РЭС Навигатор — Боград

Первая офлайн-ориентированная версия Android-приложения для водителя-электромонтёра.

## Что есть в этой версии
- Поиск объектов по названию, типу, номеру и примечаниям.
- Определение текущего GPS-положения.
- Расстояние и азимут до выбранного объекта.
- Добавление объекта с координатами, полученными по GPS.
- Редактирование и удаление объектов.
- Импорт/экспорт CSV через системный выбор файлов.
- Хранение данных локально в приложении.
- Не требует сервера или учётной записи.

## Честные ограничения
Это исходный Android-проект, а не уже собранный APK. Для сборки нужен Android Studio и Android SDK. Первый запуск/сборка обычно требуют интернета для скачивания Gradle-зависимостей.
В этой стартовой версии нет встроенной подложки дорог/спутниковых снимков. GPS, поиск, список объектов и сохранённая база работают офлайн. Для полноценной офлайн-карты надо добавить региональные тайлы/векторную карту и проверить лицензию источника данных.

Приложение не содержит реальных координат объектов Боградского РЭС. Их нельзя достоверно угадать. Импортируйте согласованную ведомость объектов с координатами либо добавляйте объекты на месте.

## Сборка
1. Установите Android Studio.
2. Откройте папку проекта `RES_Navigator_Bograd` как проект.
3. Дождитесь синхронизации Gradle.
4. Подключите Android-телефон с USB debugging либо используйте эмулятор.
5. Нажмите Run.

Чтобы собрать APK: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Формат CSV
Заголовки:
`id,name,type,latitude,longitude,description,access,photoUri`

Пример:
`BGR-001,Опора 17,Опора,54.123456,90.123456,Линия 10 кВ,Подъезд с грунтовой дороги,`

Координаты в примере вымышлены — не использовать для навигации.

## Важная безопасность
Приложение — справочный инструмент, не заменяет диспетчерские указания, наряд-допуск, схемы и инструкции по электробезопасности. Перед выездом проверяйте актуальность координат и доступность подъезда. Не приближайтесь к повреждённым проводам и электроустановкам ради уточнения точки.
